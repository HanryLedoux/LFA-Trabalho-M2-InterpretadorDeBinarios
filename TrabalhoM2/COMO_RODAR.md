# Como rodar

Requisito: JDK 11 ou superior.

**1. Compilar** (na pasta do projeto):

```
javac -encoding UTF-8 *.java
```

**2. Executar no terminal (modo interativo):**

```
java Main
```

Digite os comandos (ex.: `A = 10`, `Show ( A )`, `log(1000)`) e `FIM` para sair.

**3. Executar um arquivo:**

```
java Main exemplo.txt
java Main teste_operacoes.txt
```
